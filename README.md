# Kanban System

Локальная корпоративная система управления задачами на базе Kanban. Проект строится как модульный монолит на Next.js, TypeScript, Prisma и PostgreSQL.

- [Состояние проекта](docs/PROJECT_STATUS.md) — только фактически реализованные и незавершённые функции, последние подтверждённые проверки и текущий следующий срез.
- [Архитектура](docs/ARCHITECTURE.md) — границы модулей и архитектурные решения.
- [База данных](docs/DATABASE.md) — модели и ограничения текущей Prisma-схемы.
- [API](docs/API.md) — реализованные HTTP-маршруты и контракты.
- [Краткий контекст для AI-агентов](docs/AGENT_BRIEF.md) — краткие указания, где искать правила и состояние.

## Локальная разработка

Требуются Node.js, совместимый с `package.json`, npm и PostgreSQL через Podman или Docker Compose.

```bash
npm install
cp .env.example .env
podman compose up -d
npm run db:migrate
npm run db:seed
npm run dev
```

Приложение по умолчанию доступно по адресу `http://localhost:3000`. Seed предназначен для development/test. Не запускай команды сброса базы данных без явного разрешения.

## Основные проверки

```bash
npm run typecheck
npm run lint
npm run test:unit
npm run test
npm run build
```

`npm run test` запускает Playwright. Для API-тестов база данных и тестовое окружение должны быть доступны согласно конфигурации проекта.
